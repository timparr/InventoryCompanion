# InventoryCompanion - Auto Bank & Inventory Tracker

InventoryCompanion is an Elder Scrolls Online add-on for crafted-item bank transfers, inventory and currency tracking, configurable alerts, and custom tracked-item groups.

## Installation
Install LibAddonMenu-2.0 version 43 or newer, then extract the `InventoryCompanion` folder into `live\AddOns`.
