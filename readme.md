# InventoryCompanion - Auto Bank, Item Tracker & Set Manager

### AI Disclosure
Parts of this add-on's codebase and structure were generated with the assistance of AI. The author (@Tim-P) has personally reviewed, tested, and validated all code for safety, performance, and efficiency prior to release.

All-in-one inventory automation, item tracking, stack restocking, and gear set management for The Elder Scrolls Online.

### Features
*(Almost all of these can be turned off in the settings so you don't have to use all of them)*

#### Bank Helpers
* **Automated Banking:** Quickly deposit and withdraw crafted items so that you can pre-craft more in one go.
* Automatically merge items in your bag onto stacks in a house storage chest when you open it.
* Adds "Withdraw 1" and "Withdraw (all except 1)" options to the right-click menu when moving stacks.

#### Bag Space Monitors
* Progress bar style "fullness" meters for your bag and bank.
* Currency tracker: see how much gold you have. Coming soon: other currencies like Tel-Var, event tickets, etc.

#### Live Item Tracker
* **Live Item Tracker:** Real-time floating HUD overlay tracking whatever items you find useful.
* Pre-made item lists (that I find useful).
* Choose for each item if you want it shown all the time (even when you don't have any), when there are some in your account anywhere, or only when they are in your bag.
* Summarize groups or not. The "treasure maps" group when summarized, for example, will just show one row with how many maps you have. If it isn't summarized, you will get a row for each map you have.
* *Coming soon:* Create your own rules for groups. Add wildcards like `*map*`, or individual items.

#### Profile Management
* Choose for each character if they want to use the master setup, or if they want to watch different items each.
* Copy profiles from other characters or the master list.
