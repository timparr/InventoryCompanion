# ESOUI Release Standards Review

Complete this review against the current [release checklist](./ReleaseChecklist.md) after release code, manifest, and description inputs are final. Save a completed copy as `ReleaseReview.md` in this folder. The package script requires the review and its timestamp to be within 24 hours, and requires the review to postdate every release input.

## Review confirmations

- [ ] ESOUI release guidance, upload rules, and linked prohibited-functionality guidance
- [ ] House-chest transfers follow a player-opened interaction and supported protected APIs; record relevant precedent or unresolved concerns
- [ ] Addon globals, saved-variable names and scope, UI names, and event filters
- [ ] Current API versions and every non-optional dependency minimum version
- [ ] Upload description, AI disclosure, credits, licensing, and install information
- [ ] Release tests and exact ZIP contents

## Notes and references

Record relevant version checks, test results, and any ESOUI staff clarification here. Do not mark the review approved while a required compliance question remains unresolved.
